# ROADMAP_2D — вектор развития SceneEngine

## North star

**Фабрика контента для 2D-сцен**, а не редактор слайдов.

Сцена — это маленький 2D-мир: окружение (лес, город, горы, офис, студия),
физические объекты (машина, дорога, деревья, здания, стол, лампа, человек),
у которых есть **механизмы** (колёса, качание, пар, мигание, ходьба) и **ключи**
на локальном таймлайне (в какой момент механизм включить, ускорить, остановить).

Всё детерминировано: `window.scene.seek(t)` — единственный источник времени.
Один и тот же `t` даёт один и тот же кадр в браузере, редакторе и рендере.

Позже: ригированные персонажи, walk/idle-циклы, липсинк по озвучке.

## Принципы

1. **Сцена — код.** HTML/CSS/JS, не JSON-конструктор нод.
2. **Время — снаружи.** Никаких `rAF`, `Date.now`, `setInterval` в сцене.
3. **Объект — переиспользуемый сниппет.** Механизмы именованы.
4. **Ключи — детерминированные.** `SceneKit.cues` + `integrate`.
5. **Окружение — слои.** Параллакс через `data-depth`.
6. **ИИ — первый пользователь.** Библиотека и API должны быть машинночитаемыми.
7. **Не UI-карточки.** Если объект не существует в физическом мире — это не сцена.

## Не делаем сейчас

- интерактивные клики/состояния;
- полноценный нодовый редактор;
- 3D/WebGL;
- риги и липсинк до Phase 4–5.
