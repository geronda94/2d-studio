# UX-аудит интерфейса и предложения

> 2026-09-19. Детальный разбор навигации, экранов, меню и дублей. Цель — интуитивность,
> группировка, единые паттерны. Код не менялся.

## 1. Карта интерфейса (как есть)

| Экран / маршрут | Что | Стиль |
|---|---|---|
| `/` Home | список проектов + «Новый проект» | светлый |
| `/project/:slug` Project | папки + «Настройки» | светлый |
| `/project/:slug/settings` Project Settings | Общее, Стили (кабинет) | светлый |
| `/folder/:id` Folder | презентации внутри папки | светлый |
| `/p/:slug` Player (MainPresentation) | плеер + редактор | тёмный |

Модалы/оверлеи (тёмные): SlideEditor, PresentationSettings, ColorLibrary, RenderManager,
MediaLibrary, ComponentSelect, AIVoice, AiAssistant, DynamicJsonEditor, Icon/EmojiPicker, TimePicker.
Плюс панели плеера: `SlidePresentation` (сайдбар слайдов), `AudioTimeline`, `DirectorDebugPanel`.

## 2. Проблемы (найдено)

### 2.1 Две визуальные вселенные
Админка (Home/Project/Folder) — светлая на Tailwind, плеер и модалы — тёмная на токенах.
Переход между ними резкий, паттерны кнопок/диалогов/empty-state разные. Нужен явный принцип:
**админка = светлая, креатив = тёмная**, но с едиными компонентами (Button, Modal, Toast, Field).

### 2.2 Настройки размазаны
- Проект: `/project/:slug/settings` (Общее, Стили).
- Презентация: `PresentationSettingsModal` (пресет/лок, вариант, палитра, шахматка, AI).
- Слайд: `SlideEditorModal` (поля + дубль бейджа пресета/палитры).
- Палитра: `ProjectSettings` (кабинет) **и** `ColorLibraryModal` (из редактора слайда) — два разных UI цвета.
Пользователь не знает, где что менять.

### 2.3 Дубли действий
- «Рендер-ферма» есть и в шапке плеера, и в нижнем тулбаре, и в папках Project/Folder.
- «Быстрый рендер» portrait/landscape — в шапке; «Рендер-ферма» — внизу.
- Пресет/лок: в `PresentationSettingsModal` и бейдж-часть в `SlideEditorModal`.

### 2.4 Шапка и тулбар плеера перемешаны
Верх: quick-render×2, render-farm, settings, close.
Низ: play, audio, mobile, sidebar, edit, fullscreen, media, render-farm, debug.
Логика группировки неочевидна; часть функций дублируется; часть (AI, brief) спрятана.

### 2.5 AI спрятан
`AiAssistantModal` открывается только из модала настроек презентации. Для новой
ключевой ценности («человек даёт команды, ИИ предлагает») это слишком глубоко.

### 2.6 Нет единой навигации
Home → Project → Folder → Presentation — только кнопки «назад» (частично). Нет хлебных
крошек, нет быстрого перехода к настройкам из плеера, нет глобального переключателя.

### 2.7 Библиотека тем недоступна из UI
Витрина палитр отключена на главной; осталась только внутри кабинета. Нет раздела «Мои темы».

### 2.8 Brief без UI
API `GET/PUT /projects/{id}/brief` есть, а формы в интерфейсе нет.

### 2.9 Разнобой мелочей
- Разные empty-state и подтверждения (где-то `confirm`, где-то свой модал, где-то тост).
- Хоткеи (P/M/S/E/F/D) не отображаются пользователю (только в title кнопок).
- EndMarker показывается только в режиме редактора (ок), но сайдбар по умолчанию скрыт.
- «Прочее» в группах токенов — свалка legacy.

## 3. Предложения (по приоритету)

### P1. Единый «AppShell» + хлебные крошки (навигация)
Общая рамка: Home → Проект → Папка → Презентация с breadcrumbs и единой кнопкой «Настройки».
Быстрые действия в крошках: «к настройкам проекта», «к настройкам презентации».

### P2. Сгруппировать тулбар плеера (3 зоны)
- **Слева (навигация):** сайдбар слайдов, добавить слайд, мобильный вид.
- **Центр (воспроизведение):** play/pause, тайм, озвучка, debug.
- **Справа (действия):** `Экспорт ▾` (быстрый portrait/landscape + рендер-ферма — одно меню),
  `Вид ▾` (fullscreen/mobile/debug), `Данные ▾` (медиа, аудио, AI), `⚙` (настройки презентации).
Убрать дубли портрет/ландшафт/ферма из шапки.

### P3. AI — первичная точка входа
Кнопку «✨ AI» вынести в тулбар плеера и в Project («Сгенерировать презентацию»).
Внутри — review-diff (уже есть). Добавить вкладку «AI» в настройках как второй вход.

### P4. Единый «Центр настроек» с табами
- **Проект:** Общее · Темы/Стили (кабинет) · Brief · Участники (задел).
- **Презентация:** Стиль · Тема · Аудио · Экспорт · AI.
Модал презентации оставить, но визуально привести к тому же паттерну табов.
Палитру (`ColorLibraryModal`) оставить только как пикер конкретного поля слайда; всё
проектное управление — в кабинете, чтобы не было двух центров.

### P5. Раздел «Темы» (библиотека)
Вернуть витрину как отдельный экран/секцию «Темы»: общие шаблоны + «Мои темы» + форк.
(Данные уже есть: `/projects/palettes`, `is_template`, `fork`.)

### P6. Form брифа
Форма `about/audience/tone/must/forbidden/voice` к проекту (сейчас только API). Влияет на AI.

### P7. Единые UI-примитивы
`Button`, `Modal`, `Toast`, `Field`, `EmptyState`, `ConfirmDialog` — один вид во всех экранах.
Тосты вместо `confirm` где уместно; единый стиль диалогов.

### P8. Хоткеи и помощь
Шпаргалка хоткеев (клавиша `?`), инлайн-подсказки на пустых экранах, онбординг-чеклист
для нового проекта («задай бриф → выбери тему → сгенерируй слайды → озвучь → рендер»).

### P9. Мелочи
- Группу токенов «Прочее» — свернуть по умолчанию.
- Сайдбар слайдов по умолчанию открывать в режиме редактирования.
- Единый индикатор сохранения/ошибок.

## 4. Карта перегруппировки меню (наглядно)

```
AppShell
├─ Хлебные крошки: Home / Проект / Папка / Презентация
└─ Быстрые действия: [Настройки проекта] [AI] [Экспорт]

Player (плеер)
├─ Слева:  Сайдбар слайдов · +Слайд · Мобильный
├─ Центр:  ▶/⏸ · тайм · 🔊 озвучка · Debug
└─ Справа: [Экспорт ▾] [Вид ▾] [Данные ▾] [✨ AI] [⚙]

Настройки
├─ Проект:       Общее · Темы/Стили · Brief · Участники
├─ Презентация:  Стиль · Тема · Аудио · Экспорт · AI
└─ Слайд:        Контент (поля) · Вариант слайда
```

## 5. Что не трогать (осознанно)
- Хоткеи P/M/S/E/F/D — привычные, только показать.
- `DirectorDebugPanel`/`AudioTimeline` — про-инструменты, оставить, но визуально отделить.
- Светлая админка + тёмный креатив — сохранить как намеренное разделение, унифицировав компоненты.

## 6. Порядок внедрения
1. P7 примитивы (без них всё остальное разъедется) — база.
2. P1 крошки + P2 тулбар плеера — самое заметное.
3. P3 AI-вход + P4 табы настроек + P6 бриф.
4. P5 темы, P8 онбординг, P9 мелочи.
