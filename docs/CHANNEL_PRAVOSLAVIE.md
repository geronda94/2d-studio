## 1. Позиционирование

- **Имя:** «Механизм».
- **Идея:** как устроено то, что кажется очевидным. Социальная история,
  пропаганда/маркетинг, семья и выбор.
- **Тон:** обычный человек, короткие фразы, факты, один острый вывод.
- **Визуал:** тёплая строгость. Графит-коричневая база, золото `#D4A843`,
  приглушённый синий для схем. Без стоковых ангелов/свечей/апокалипсиса.
- **Первый кадр = обложка.** Крупный текст, читаемый с телефона.

## 4. Формулы сцен

| Формула | Шаблон | Когда |
|---|---|---|
| Вход в выпуск | `prav-studio-host` | ставка → событие → немыслимое → парадокс |
| Панель экспертов | `prav-studio-panel` | ведущий + священник + историк |
| Интервью с социологом | `prav-studio-sociologist` | механизмы, статистика |
| Историческая сцена | `prav-empire-history` / `prav-ancient-rus` / `prav-soviet-history` | эпоха + ведущий + эксперт |
| Таймлайн | `prav-timeline` | 1905 → 1917 → 1937 → 1953 → 1991 |
| Цитата в храме | `prav-church-quote` | священник + крупная цитата |
| Финал | `prav-outro` | вывод + подписка/контакт |

Монитор в студии: `props.monitor_media` (картинка) или `props.monitor_video`
(видео). Пока URL задаётся в Props JSON; дальше — медиа-пикер.

## 5. Сценарий → сцены

1. Прочитать сценарий (только текст для голоса).
2. Разбить на смысловые блоки: вход, факт, «тогда», «сейчас», вывод, финал.
3. На каждый блок — 1 сцена 4–7 секунд.
4. Выбрать мир: студия / храм / эпоха / таймлайн.
5. Выбрать каст: ведущий / эксперт / массовка.
6. Заполнить `caption`/`quote`/`monitor_media`.
7. Проверить 16:9 и 9:16.
8. Отрендерить.

Правило: **не дублировать озвучку дословно**. На слайде — смысл, цифра, образ.

## 6. Визуальные правила

- Один главный акцент на сцену.
- Крупный текст, короткие фразы.
- Золото — ключевое слово/цифра; красный — потеря/угроза.
- Не показывать лики крупно; храм — арками, светом, свечами.
- Историческая эпоха — через среду и детали, не через костюмную бутафорию.
- Нижняя треть с именем/ролью — обязательна для говорящего.
- Монитор — не декор: на нём картинка/видео по теме.
- Таймлайн — ось, развилки, «рифмы» эпох одним цветом.

## 7. Как добавить выпуск

1. Создать папку/презентацию в проекте `pravoslavie`.
2. Собрать сцены из шаблонов (`Scenes`).
3. Заполнить `caption`/`quote`/`monitor_media`.
4. Проверить тайминг: старты ≥ 2000 мс, длительность 4–7 с.
5. `EndMarker` = последняя сцена + 1000 мс.
6. Проверить через `/p/{id}?slide=N`.
7. Отрендерить.

## 8. Ограничения

- Персонажи — плейсхолдеры, не финальные риги.
- Липсинк ещё не подключён.
- Монитор принимает URL, не drag-n-drop из медиатеки.
- Исторические костюмы условные.
