# PAPER CAST ROADMAP — позы, персонажи, скелеты, 2.5D

Обновлено: 2026-10-27. Вектор: 2D-first, без Babylon/3D-моделей.
Текущий рантайм: `core/public/vendor/paper-cast.js` (`?v=7`).
Студии: `character-studio.html` (скины/липсинк), `pose-studio.html` (позы/жесты).

## 1. Где мы сейчас

Есть:

- общий скелет на 15 узлов, 2-bone IK рук, углы ног, один скин-палитра на
  персонажа;
- 31 статичная поза, 82 фонемы, 18 визёмов, эмоции, взгляд, моргание;
- Pose Studio: перетаскивание кистей, слайдеры тела/головы/ног, лимиты
  суставов, пресеты в localStorage, экспорт JSON и JS для сцены,
  предпросмотр A→B (ping-pong / цикл / один раз);
- зачаток 2.5D: `yaw` ±0.75 — поворот головы, дальняя рука за торсом;
- **клипы жестов**: 8 библиотечных (`wave`, `point`, `explain`, `shrug`,
  `think`, `thumbsUp`, `present`, `nod`) с антиципацией, перелётом и
  возвратом; `setClip` / `playClip` / `registerClip`, easing по сегментам;
- **конструктор персонажа** `character-builder.html`: пропорции головы,
  плеч, бёдер, рук и ног, лицо, причёски, 5 верхов и 3 низа, палитры,
  пресеты, экспорт;
- **животные** `paper-cast-animals.js`: пёс, кот, свинья, корова, курица,
  голубь, орёл, синица, жук, пчела — свой скелет, позы, шаг/бег/полёт,
  скелет-оверлей;
  грузятся в сцену по `PaperCastAnimals`.

Чего нет (и почему жесты «кривые»):

- нет ограничений на **угол плеча/бедра** и самопересечение — IK может
  выдать локоть внутрь торса;
- `playGesture` остался грубым blend'ом — для сцен использовать клипы;
- позы задаются **целями кистей**, а не углами: тонкая кисть/плечо не
  настраиваются напрямую;
- пропорции: голова, плечи, бёдра, руки, ноги — да; общая «толщина»
  корпуса и пресеты «ребёнок/взрослый» — ещё нет;
- гардероб — 5 верх/3 низ без отдельной JSON-библиотеки предметов;
- зоопарк — 10 видов (включая насекомых); общего `family`-контракта ещё нет;
- 2.5D — только намёк, профиля нет.

## 2. Принципы

1. Детерминизм: кадр = функция от `t`, `seek(t)`, никаких часов внутри сцены.
2. Никакого рантайм-3D и ретаргета Mixamo. Только слоистая 2D-графика.
3. Поза и анимация — **данные** (JSON), а не код сцены.
4. Один контракт рига для всех скелетов; скины и одежда — плагины.
5. Любое авторское состояние проверяется лимитами и QA до попадания в сцену.

## 3. Архитектура

### 3.1. Rig Contract v2

```
Skeleton  = { id, family: humanoid|quadruped|avian|insectoid,
              bones: [{id, parent, len, rest, limits:{x,y,z}}],
              solve: (pose) => joints, floor, anchors }
Pose      = { body{x,y,rot}, head{tilt,turn,nod}, arms[], legs[], yaw? }
Clip      = { duration, tracks: [{bone, axis, keys:[{t,v,ease}]}], loop }
Skin      = { palette, proportions, face, hair, outfit }
```

- `limits` — диапазоны по каждой оси, а не только «дотянуться».
- IK решает цель, затем **clamp по лимитам**; наружу отдаём `validatePose`.
- `family` определяет число конечностей и походку, но интерфейс один.

Сделано в этом шаге: `LIMITS`, clamp в `makeSkeleton`, `validatePose`,
`skeleton(pose, yaw)`, `setPoseObject`, `setLife`, `setYaw`,
`registerPose`.

### 3.2. Жесты и анимация

- Пресет позы (JSON) → `PaperCast.registerPose(name, pose)`.
- `setPoseKeys([{at, pose}, …])` уже умеет объекты и имена.
- Следующий слой: **клипы** с кривыми на кость (`ease`, overshoot), вход
  и выход жеста, аддитивное дыхание.
- Циклы: `life` (дыхание/качание/кивок) с амплитудами; далее — gait-циклы
  (шаг, бег, взмах крыльев) как отдельные clip-пресеты.
- Экспорт из Pose Studio: JSON + `registerPose` + `setPoseKeys` для сцены.

### 3.3. Пропорции и лицо

Параметры (все скины, без правки костей):

- тело: `build`, `shoulder`, `hipWidth`, `armLen`, `legLen`, `neckLen`;
- голова: `headScale`, `jaw`, `earSize`;
- лицо: `eyeSize`, `eyeGap`, `brow`, `nose`, `mouthW`, `lip`;
- волосы: `hairStyle` + цвет/длина (short, bob, bun, bald, cap).

Реализация: `makeSkeleton` масштабирует сегменты от `RIG`, `drawFace`
читает `skin.face`. Пресеты пропорций — JSON рядом со скинами.

### 3.4. Гардероб

Слоты, а не один `drawTorso`:

```
outfit = { top, bottom, outer, shoes, head, accessory }
top     = { kind: shirt|tee|hoodie|dress|coat, palette, collar, cuffs, pocket, pattern }
```

- Каждый kind — функция рисования поверх тела; обувь/аксессуары — отдельные.
- Слои рисуются в порядке: низ → верх → верхняя одежда → обувь → аксессуары.
- Библиотека: `core/public/wardrobe/*.json` + превью в Character Lab.
- Совместимость: `covers` (рукава/длина), чтобы IK и манжеты не спорили.

### 3.5. Скелеты (зоопарк)

Семейства и минимум:

| family | bones | позы | походка |
|---|---|---|---|
| humanoid | 15 | 31 | idle/walk/run |
| quadruped (кот, пёс, свинья, корова) | 18–22 | sit/lie/walk/run | 4-beat gait |
| avian (курица, орёл, голубь, синица) | 14–18 | stand/peck/flap/perch | hop/flap |
| insectoid (жук, пчела) | 12–16 | crawl/fly | 6-leg tripod |

Общее: `family` + `solve` + `poses` + `gaits` + `draw`-слои. Отдельные
скины/палитры. Переключение — `PaperCast.create(canvas, {skeleton:'dog'})`.

Порядок: quadruped (dog/cat) → avian (chicken/dove) → pig/cow → insects.
Каждое семейство проходит те же QA: 0 утечек, детерминизм, 16:9/9:16.

### 3.6. 2.5D и повороты

Что реально:

- **3/4 (±0.75)**: голова уже поворачивается (сдвиг черт, сужение дальнего
  глаза, скрытие дальнего уха, тень на дальней стороне), дальняя рука
  уходит за торс и темнеет. Это безопасно и уже в студии.
- **Профиль (90°)**: нужен второй набор проекций — боковая голова
  (силуэт носа/подбородка, одно ухо, затылок), боковой торс и конечностей,
  либо параметрическая маска головы. Это отдельный арт-набор, не «сдвиг
  пикселей».
- **Походка в 3/4**: 2.5D-перемещение по сцене (x, масштаб, параллакс) уже
  возможно; поворот корпуса — через yaw + перерисовку плеч/бёдер.

Честно: полноценные 360° на плоских слоях не выйдет без боли; 3/4 + профиль
на отдельном наборе — реалистичный максимум, и он даёт «идёт, повернулся,
заговорил».

## 5. Риски

- **Самопересечения**: IK не знает о торсе; лечим лимитами плеча и
  «мягким» отталкиванием цели от корпуса.
- **Костюмы vs IK**: длинные рукава/полы пальто требуют своих крючков;
  слоты должны отдавать `covers`.
- **Зоопарк**: каждое семейство — свой solve и арт; не пытаться сделать
  универсальный «мета-риг» на 100 костей.
- **Профиль**: не обещать 360°; 3/4 + отдельный профиль.
- **Детерминизм**: студия может использовать rAF, сцена — только `seek`.

## 6. Как пользоваться сейчас

0. `http://localhost:5175/character-builder.html` — персонаж/животное:
   тип, пропорции, лицо, одежда, позы, пресеты, экспорт.
1. `http://localhost:5175/pose-studio.html`
2. Тяните кисти, крутите слайдеры, следите за «Лимитами».
3. Save — пресет в localStorage; Export → JSON / Scene JS.
4. В сцене: `PaperCast.registerPose('myPose', {...})`, затем
   `cast.setPoseKeys([{at:0,pose:'neutral'},{at:900,pose:'myPose'}])`.
5. A→B: выберите позы, Play; ping-pong/цикл/один раз; life — дыхание.
