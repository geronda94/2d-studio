# ANATOMY RIG — диапазоны суставов и правила движения

Дата: 2026-10-28. Относится к Canvas-персонажам `PaperCast` и ко всем
скелетам (`humanoid`, `quadruped`, `avian`, `insectoid`).
Цель: движения задаются **не на глаз**, а таблицей анатомических
диапазонов; IK и FK работают внутри этих диапазонов, редактор показывает
и не даёт выйти за них.

---

## 1. Почему это нужно

Плохой жест («рука вывернута», «локоть выше кисти», «кисть не показывает
пальцы») — это почти всегда одно из трёх:

1. IK выбрал не ту сторону сгиба (pole vector) — локоть ушёл вверх/внутрь.
2. Сустав вышел за анатомический диапазон (локоть «назад», запястье
   «в другую сторону», колено «в минус»).
3. Две оси смешаны: сгибание и вращение (пронация) считаются одной
   ручкой, поэтому ладонь смотрит не туда.

Поэтому в риге есть **две оси на сустав** (где они есть анатомически),
жёсткие пределы и отдельная пронация предплечья.

---

## 2. Анатомические диапазоны (взрослый человек, градусы)

Нормы — клиническая гониометрия; значения округлены и приведены к
диапазону «мягкая граница» (90 % от максимума), который используется
в живом редакторе. Источники в конце документа.

### 2.1. Плечевой пояс и плечо (glenohumeral + scapula)

| Движение | Полный диапазон | Мягкий предел в риге |
|---|---|---|
| Сгибание (вперёд) | 0…180 | 0…170 |
| Разгибание (назад) | 0…60 | 0…55 |
| Отведение (в сторону) | 0…180 | 0…170 |
| Приведение (через тело) | 0…45 | 0…40 |
| Внутренняя ротация | 0…70 | 0…65 |
| Наружная ротация | 0…90 | 0…85 |

Правило: при подъёме руки выше 90° лопатка даёт ~1/3 движения
( scapulohumeral rhythm 2:1). В 2D это не считаем отдельно, но
ограничиваем плечо 170°, а не 180°.

### 2.2. Локоть и предплечье

| Движение | Полный | Мягкий |
|---|---|---|
| Сгибание | 0…150 (до 160 у худых) | 0…150 |
| Переразгибание | 0…10 | 0 (запрещено) |
| Пронация | 0…85 | −85…85 (знак = сторона) |
| Супинация | 0…85 | −85…85 |

Локоть — **одноосевой**: только сгибание/разгибание. Вращение ладони —
это пронация предплечья, а не «поворот кисти». В риге:

- `fk.elbow` — сгибание 0…150;
- `arm.handRot` — пронация −90…90 (0 = ладонь к телу).

### 2.3. Запястье

| Движение | Полный | Мягкий |
|---|---|---|
| Сгибание (ладонью к себе) | 0…80 | 0…80 |
| Разгибание (тыл кисти) | 0…70 | 0…70 |
| Лучевое отклонение | 0…20 | 0…20 |
| Локтевое отклонение | 0…30 | 0…30 |

В риге две оси:

- `fk.wrist` — сгибание/разгибание −80…70 (в плоскости экрана);
- `arm.handRot` — пронация/супинация −90…90 (большой палец меняет сторону).

Отклонение кисти (radial/ulnar) в плоском риге не рисуем отдельно:
оно читается как небольшой наклон кисти, поэтому заложено в
`handRot` и в пресеты пальцев.

### 2.4. Пальцы (фаланги)

| Сустав | Сгибание | Разгибание |
|---|---|---|
| MCP (пястно-фаланговый) | 0…90 | 0…30 |
| PIP (проксимальная фаланга) | 0…100 | 0…10 |
| DIP (дистальная фаланга) | 0…70 | 0…10 |
| Большой: CMC (отведение) | 0…70 | — |
| Большой: MCP | 0…50 | 0…10 |
| Большой: IP | 0…80 | 0…10 |

Правило сгиба: `curl` 0…1 → MCP = 90·curl, PIP = 100·curl,
DIP = 70·curl. Для указательного жеста MCP/PIP/DIP = 0 у указательного,
остальные — 1. Для «класс» большой палец разогнут, остальные сжаты.

### 2.5. Таз и бедро

| Движение | Полный | Мягкий |
|---|---|---|
| Сгибание (колено согнуто) | 0…120 | 0…120 |
| Разгибание | 0…30 | 0…30 |
| Отведение | 0…45 | 0…45 |
| Приведение | 0…30 | 0…30 |
| Внутренняя ротация | 0…45 | 0…45 |
| Наружная ротация | 0…45 | 0…45 |

В плоском фронтальном риге видно **отведение/приведение** (нога в
сторону), поэтому `leg.swing` = −30…45. Сгибание бедра (шаг вперёд)
появится в 2.5D-профиле и в походке.

### 2.6. Колено и стопа

| Движение | Полный | Мягкий |
|---|---|---|
| Колено, сгибание | 0…135 | 0…135 |
| Колено, переразгибание | 0…10 | 0 (запрещено) |
| Голеностоп, тыльное сгибание | 0…20 | 0…20 |
| Голеностоп, подошвенное | 0…50 | 0…50 |
| Инверсия | 0…35 | 0…35 |
| Эверсия | 0…15 | 0…15 |

### 2.7. Позвоночник и шея

| Отдел | Сгибание | Разгибание | Боковой наклон | Ротация |
|---|---|---|---|---|
| Шейный | 0…50 | 0…60 | 0…45 | 0…80 |
| Грудной | 0…40 | 0…25 | 0…20 | 0…35 |
| Поясничный | 0…60 | 0…25 | 0…25 | 0…15 |

В 2D фронтальном риге:

- `fk.spine` — суммарный боковой наклон груди + поясницы: −40…40;
- `fk.neck` — боковой наклон шеи: −45…45;
- `fk.head` — наклон головы: −30…30;
- `head.turn` (нормализованный −1…1) = ротация шеи ±80°, `head.nod` =
  сгибание/разгибание ±20°.

Распределение движения по отделам: ротация шеи — 50 % шейный отдел,
30 % грудной, 20 % поясничный. Поэтому в риге один `neck`, но
`head.turn` ограничен 0.8 от полного.

## 3. Как это работает в риге

### 3.1. Цепочка

```
root → hip → spine → neck → head
  ├→ shoulder → upperArm → elbow → forearm → wrist → hand → fingers
  └→ hip → thigh → knee → shin → ankle → foot
```

- **IK** решает позицию кисти/стопы (2-bone), из двух решений берётся
  анатомически нижний локоть/колено (поле «pole»).
- **FK** добавляет градусы поверх IK: `pose.fk`.
- **Пределы** проверяются после сложения: `clampJoint()` режет значение,
  `validatePose()` сообщает, что именно вышло за диапазон.
- **Пронация** (`handRot`) не влияет на IK: она только поворачивает кисть.

### 3.2. Правила сочетаний (coupling)

- Плечо + лопатка: подъём > 90° ограничиваем 170°, а не 180°.
- Локоть + пронация: при сгибе > 90° пронация ограничивается ±70°,
  иначе предплечье «выкручивается».
- Запястье + пронация: суммируются, но каждая ось в своём диапазоне.
- Колено + голеностоп: при сгибе колена > 100° тыльное сгибание
  стопы ограничивается 10°.
- Наклон корпуса + шея: голова компенсирует наклон на 50 %, чтобы
  взгляд оставался горизонтальным (`compensateHead`).

### 3.3. API

```js
PaperCast.ANATOMY                       // таблицы диапазонов
PaperCast.jointRange('elbow', 'flex')   // [0, 150]
PaperCast.clampJoint('wrist', 'flex', 120) // 70
PaperCast.anatomyReport(pose)           // [{joint, axis, value, range, ok}]
PaperCast.FINGER_CURL                    // curl -> MCP/PIP/DIP
```

`anatomyReport` используется студиями: слайдер показывает диапазон,
а при выходе за предел подсвечивается.

## 4. Перенос на нечеловеческие скелеты

Правило: **роли важнее названий**. Любой скелет раскладывается на
канон `root → proximal → distal → end` и получает таблицу диапазонов.

| Семейство | Канон | Проксимальный | Дистальный | Конец |
|---|---|---|---|---|
| humanoid | hip → shoulder | upperArm | forearm | hand |
| humanoid | hip | thigh | shin | foot |
| quadruped (пёс/кот) | scapula | humerus | radius/ulna | carpus |
| quadruped | pelvis | femur | tibia/fibula | hock |
| avian | shoulder | humerus | radius/ulna | carpometacarpus |
| avian | pelvis | femur | tibia | tarsometatarsus |
| insectoid | coxa | femur | tibia | tarsus |

Ориентиры для четвероногих (литература по ветеринарной гониометрии,
собака/кошка):

| Сустав | Диапазон |
|---|---|
| Плечо (flex/ext) | 40…165 |
| Локоть | 30…165 |
| Запястье | 20…90 (сгибание) |
| Бедро | 40…160 (сгибание) |
| Колено (stifle) | 40…165 |
| Скакательный (hock) | 20…165 |

Птицы: плечо 0…90, локоть 0…120, запястье 0…90; крыло складывается
в три шага (плечо → локоть → запястье), как человеческая рука.

Насекомые: тазик (coxa) 0…60, бедро (femur) 0…120, голень (tibia)
0…120, лапка (tarsus) 0…90; ходьба — трипод (пары 1+3 и 2).

## 5. Что проверять в QA

- Ни один сустав не выходит за диапазон в 31 позе и 10 животных.
- Локоть всегда ниже кисти при поднятой руке (pole = низ).
- Кисть при `handRot = 0` показывает ладонь к телу, большой палец
  вперёд; при `handRot = ±90` — профиль.
- Колено не уходит в минус, стопа не «клюёт» больше 50°.
- `anatomyReport` пуст (или только предупреждения) на всех пресетах.

  Goniometry*, 5th ed. — базовые таблицы ROM.

  нормы для собак/кошек.
