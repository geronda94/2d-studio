## Скелет: 2 оси на сустав, диапазоны, шея, платье (2026-10-29, ночь)

- **`PaperCast.JOINT_RANGES`** — один источник правды для движений:
  `spine ±40`, `neck ±40`, `head ±28`, `sh` подъём −55…170, `elbow` 0…150,
  `wrist ±70`, `hip` отведение −25…90, `knee` сгиб 0…135, `ankle` −45…25.
  `jointRangeFor(range, side)` зеркалит значения для правой стороны
  (подъём правой руки — отрицательный), `LIMITS.fk` выводится как
  симметричная страховка для движка.
- **Pose Studio — две оси на каждый сустав**: точка на суставе тянет
  родительскую кость (плечо/бедро/шея), кольцо рядом — собственный сгиб
  (локоть, колено, стопа, шея). Кольцо следует за указателем, скачки
  больше 60° (указатель пересёк сустав) игнорируются.
- **Голова** — 2D-перетаскивание: влево/вправо поворот лица (±0.8),
  вверх/вниз наклон (±28°).
- **Видимый диапазон**: при выборе сустава рисуется дуга допустимого
  сектора от направления покоя + пунктир до текущего положения; HUD
  показывает обе оси и их границы.
- **Слайдеры FK** в панели получают границы по стороне (локоть R:
  −150…0 и т. п.).
- **Шея**: `tapered()` собирался из двух дуг с хордой и вырезал середину —
  между шеей и воротником просвечивал фон. Капсула теперь строится

## Профиль: рука, стопа, воротник + осанка (2026-10-29, вечер)

- **Ось наклона корпуса перенесена в талию** (`527` вместо таза): FK-спина
  наклоняет торс от пояса, шея и голова едут вместе с ним; центры шеи и
  воротника пересчитываются по наклону, голова доворачивается на `spine * 0.8`.
- **Борода по форме лица** (`oval/round/square/heart`) вместо общей маски,
  пряди-штрихи, усы по ширине лица, отдельный `beardColor`.
- **Кисти** уменьшены до `1.22`, пальцы начинаются ниже (y 26), манжета
  запястья шире (24×12); пиджак берёт `coatColor`, как пальто.
- **Профиль**:
  - одна видимая рука проецируется на боковой силуэт (плечо внутрь на 12 px),
    «подушка» плеча убрана; рука рисуется **под** торсом, если кисть у бедра,
    и **поверх**, если жест поднят/впереди (wave, point, think, explain);
  - если жест делает дальняя рука, в профиле показывается она
    (сравнение по подъёму кисти + выносу);
  - стопа разворачивается носком в сторону поворота (`yaw < 0` → зеркально);
  - шея висит от воротника, а не от центра черепа: наклон головы её больше
    не вывешивает за затылок;
  - воротник у tee/vest/dress — плоская бейка, у shirt/coat/jacket —
    стоячий воротник; шея рисуется до торса, поэтому срез шеи закрыт.
- QA 22/22 на dev и на dist; `paper v31`; dist пересобран.

## Что уже работает

### Инфраструктура
- Отдельный compose-проект `scene-saas`.
- Frontend `http://localhost:5175`, backend `http://localhost:8002`,
  Postgres `localhost:5437` (`scene_db` / `scene_user`).
- Чистая БД, сиды тем/вариантов/пресетов, демо `http://localhost:5175/p/1`.

### Сцена
- Sandboxed iframe (`sandbox="allow-scripts"`).
- Инжект темы (CSS-переменные) и локального GSAP.
- Контракт `window.scene.seek(t)`.
- `SceneKit`: `cues`, `integrate`, `mechanism`, `parallax`, `compose`.
- Handshake: `scene-ready` → `window.__sceneReady = true`; рендерер ждёт флаг.
- Только активная сцена монтируется в плеере (`Slide.vue` `bare`).

### Данные и API
- Поля сцены в `slides`: `kind`, `duration`, `code`, `props`, `props_schema`,
  `track`, `z_index`.
- CRUD: `/presentations/{id}/scenes`, `/presentations/scenes/{id}`.
- Валидация: `code` — объект, `html/css/js` — строки, `duration > 0`.
- Длительность: `start_time + duration`; `EndMarkerSlide` синхронизируется
  с `max(start + duration) + 1000`.
- Фронт пишет сцены через `/scenes`, EndMarker — через `/slides`.

### Редактор
- Полноэкранный `SceneEditor`.
- Вкладки: Scenes / Worlds / Objects / HTML / CSS / JS / Props / Info.
- Живое превью с ручным временем и play.
- Загрузка шаблона/окружения, вставка объекта.
- Сохранение/удаление, `start_time`, `duration`, `props_schema`.

## Известные нюансы

- `SceneHost` в редакторе — `preview`, он не владеет глобальным handshake.
- В редакторе тема берётся из `.slides-container` за модалкой.
- `SceneKit` инжектится в iframe так же, как GSAP (локально, без CDN).
- В сцене нельзя использовать `rAF`, `Date.now`, `setInterval`, `Math.random`,
  бесконечные CSS-анимации.
