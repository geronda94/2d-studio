# PAPER CAST — BACKLOG

Обновлено: 2026-10-29. Приоритеты: P0 — блокеры качества, P1 — функции,
P2 — инженерия/полировка. Каждый пункт закрывается только с проверкой
на 31 позе, 10 животных, профиле (yaw ±1) и мобильном 390×844.

## P0 — качество персонажа

- [~] **Единый силуэт плеча и бедра** — опущенные руки уходят за торс
      (клип по линии плеч), низ таза не обводится. В профиле рука
      проецируется на силуэт, «подушка» плеча убрана; остался стык
      плеча в 3/4 при сильном подъёме руки.
- [x] **Фаланговые кисти** — 3 фаланги (MCP/PIP/DIP) одной трубой,
      `FINGER_CURL` в изгибе, point/peace/ok/thumb читаются. Осталось:
      анимация фаланг во времени.
- [~] **Профиль beta → профиль** — рука висит у силуэта (и уходит за торс,
      когда опущена), жест идёт поверх торса, носок стопы смотрит в сторону
      поворота, воротник закрывает срез шеи. Осталось: пятка/подошва при
      ходьбе, таз и обувь без разрывов, воротник пальто.
- [~] **Лицо** — 4 формы лица (овал/круглое/квадратное/сердце) и
      библиотеки носов/глаз/бровей/губ готовы, борода строится по форме
      лица с прядями. Осталось: веки, асимметрия, микромимика.
- [~] **Стопы** — пятка/носок, подошва с подъёмом, каблук, шнуровка,
      разворот в профиль. Осталось: шаг/походка (heel strike → toe off).

## P1 — функции и контент

- [~] **Гардероб-библиотека**: 8 верх/4 низ с превью, правила слоёв,
      узоры и аксессуары. Осталось: 20+ предметов, драпировка/складки,
      манжеты и воротники, JSON-каталог.
- [ ] **Библиотека персонажей**: сохранение в backend (`scene_assets`),

- [ ] **Анимация**: walk/run/idle циклы для человека, gait-библиотека

      сустава, зум/пан.
- [ ] **Сцены**: переходы между сценами, локации в профиль, массовка,
      камера в профиль.
- [ ] **Липсинк с аудио**: TTS/STT → виземы по таймлайну, проверка
      расхождения < 80 мс.
- [ ] **Экспорт**: превью-миниатюры персонажей/сцен.

## P2 — инженерия

- [ ] **Валидаторы**: рука не входит в торс, кисть/стопа в кадре,
      одежда не конфликтует, кость не за лимитом.
- [ ] **Производительность**: кэш статичных слоёв, ленивые canvas,
      меньше перерисовок, бюджет кадра.
- [ ] **i18n**: единые RU-термины, подписи без `live/walk/fk`.
- [ ] **API сцен**: документировать props/события персонажа.
